# 油站网点地图管理

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Element Plus、Leaflet
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

这是一个功能最小闭环前端项目，数据默认保存在浏览器localStorage中，方便后续扩展接口、权限、图表或地图能力。

## 证照管理

油站卡片额外维护经营许可证、危化品经营许可证、消防验收意见书三类到期日，代码拆在 `src/license/` 下三个业务文件，不接后台、不加依赖：

- `licenseRules.ts`：证照规则。任一过期 => “证照异常”，任一缺失 => “待补录”；到期前 30 天“即将到期”提醒。异常 / 待补录期间禁止流转营业状态（原状态保留不动），三类续办齐全后自动恢复。
- `licenseMigration.ts`：历史数据迁移。无照站点补空证照字段（页面显示“待补录”），迁移幂等并清洗脏日期。
- `useStationLicenses.ts`：页面交互。卡片证照徽标与逐类状态、内联补录 / 续办面板、流转拦截与保存提示。
